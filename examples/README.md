# Examples

Reference code for developers integrating with Annoteca's public API. This is not
part of the plugin, is not bundled, and most users never need it.

- [`api-consumer.ts`](./api-consumer.ts): a compilable walkthrough of the API. It
  detects a comment with no dependency, reads comments, creates them, watches for
  changes, and jumps to one. Copy the parts you need.

The full guide is in [../API.md](../API.md).
